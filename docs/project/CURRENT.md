| **Window Frame & Media Planner** | [`ArtifactProcessor.swift`](../../Sources/MbedCore/Pipeline/ArtifactProcessor.swift), [`FolderWatcher.swift`](../../Sources/MbedCore/Pipeline/FolderWatcher.swift) | **SOLID** | `WindowPlanner.pickFPS` and duration-scaled `WindowPlanner.pickContent` (`min(maxFrames, max(2, ceil((hi - lo) * fps)))`), default `16s` overlapping video stride on `32s` windows, live `AVFoundation` `32x32` RGB thumbnail extraction (`extractVideoCandidates`, with metadata-only fast path for `.fps` and exact frame-center timestamps `(idx + 0.5) / nativeFPS`), upright frame decoding (`appliesPreferredTrackTransform = true`), per-window thumbnail extraction (`makeThumbnailJPEG(..., atSeconds:)`), 16 kHz mono PCM decoding + 30s/15s audio windowing (`extractAudioWindows`, `encodeAudioSliceWAV`), `PDFKit` page chunking (`chunkDocument`), and `FSEventStream` directory watching (`FolderWatcher`). *Note*: Under Option A (`HeylookMLXEngine`), server-side video windowing in `heylookllm` (`video_windows.py`) uses non-overlapping `32s` stride (`lo += seconds`). |
| **Heylook HTTP Engine (Option A)** | [`HeylookMLXEngine.swift`](../../Sources/MbedCore/Engine/HeylookMLXEngine.swift) | **SOLID** | Actor speaking `POST /v1/embeddings`, `GET /v1/models` (`fetchCapabilities`, automatically invoked on first `embedBatch` call to update `maxItemsPerRequest` and `maxRequestMediaBytes`), and `DELETE /v1/requests/{id}` on `CancellationError`; retries `429`/`503`; chunks batches via `planBatches` (`<= 16` items and `<= 192 MiB` raw media bytes); formats inline document titles (`title: <filename> | text: ...`) and omits `prompt_name` on pure-media inputs for exact parity with `EmbeddingGemma2Processor` and `mlx-swift-lm`. |
| **In-Process MLX Swift Engine (Option B)** | [`NativeMLXEmbeddingGemma2.swift`](../../Sources/MbedCore/Engine/NativeMLXEmbeddingGemma2.swift), [`Package.swift`](../../Package.swift), [`build_native_mlx.sh`](../../scripts/build_native_mlx.sh) | **SOLID** | Self-contained in-process Apple Silicon GPU engine backed by `MLXVLM.EmbeddingGemma2Embedding` and `MLXLMCommon.EmbeddingGemma2`. `Package.swift` automatically links `mlx-swift` and `mlx-swift-lm` (`MLX`, `MLXLMCommon`, `MLXVLM`, `MLXHuggingFace`, `Transformers`) whenever `../../mlx/mlx-swift/Source/Cmlx/mlx/CMakeLists.txt` is present on disk (or `MBED_ENABLE_NATIVE_MLX=1`, with `MBED_DISABLE_NATIVE_MLX=1` available for fast offline SwiftPM runs). `scripts/build_native_mlx.sh` (`build` \| `test` \| `cli` \| `app`) compiles the Metal shader bundle (`default.metallib` + `embedding_gemma2_resize_axis`) via `xcodebuild`. Both `MbedApp` and `MbedCLI` default to `.nativeMLX` when `MLXVLM` is linked, so `mbed` runs 100% standalone without `heylookllm`. |
| **Multimodal & Non-Media Indexing** | [`IndexCoordinator.swift`](../../Sources/MbedCore/IndexCoordinator.swift) | **SOLID** | Indexes `.image`, `.video` (with per-window representative thumbnails and opt-in `loadAudioFromVideo` parity joining `<|video|>` and `<|audio|>` with `.text(" ")` and slicing soundtrack windows aligned to `[w.start, w.end]`), `.audio` (decoding 16 kHz mono PCM upfront so `#whole` sends a compact `<= 30s` WAV plus overlapping 30s temporal spans), `.document` (`PDFKit` `.pages(startPage:endPage:)` + rendered page thumbnails + `title`), `.text`, and `.code` (passing `title: artifact.title`), prunes deleted files via `pruneMissingArtifacts`, and supports explicit `taskOverride: EmbeddingTask?` on `search(...)`. |
