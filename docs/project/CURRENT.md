## Subsystem Grading

| Subsystem | Files | Grade | What Works Today vs. What Is Missing |
| :--- | :--- | :--- | :--- |
| **Domain & Span Model** | [`Artifact.swift`](../../Sources/MbedCore/Domain/Artifact.swift) | **SOLID** | `ArtifactKind` (`.image`, `.video`, `.audio`, `.text`, `.code`, `.document`), `ArtifactSpan` (`.whole`, `.temporal(start:end:frameTimes:)`, `.lines(startLine:endLine:)`, `.pages(startPage:endPage:)`), `ContentFingerprint`, and `SearchHit` parent-artifact grouping. |
| **Matryoshka Math** | [`EmbeddingEngine.swift`](../../Sources/MbedCore/Engine/EmbeddingEngine.swift) | **SOLID** | `vDSP`-accelerated L2 normalization, Matryoshka prefix slicing (`768`, `512`, `256`, `128`), and cosine similarity. |
| **SQLite Vector Store** | [`VectorStore.swift`](../../Sources/MbedCore/Store/VectorStore.swift) | **SOLID** (with 1 schema gap) | SQLite3 `WAL` store, atomic `upsert`, query-time Matryoshka slicing without re-indexing, and parent-artifact deduplication (1 result per file with `bestSpan` and sorted `spanMatches`). **Gap**: `isUpToDate` only checks `(byte_count, modified_ms)`, not the `videoWindowSampling` mode used when indexing. |
| **Window Frame Planner** | [`ArtifactProcessor.swift`](../../Sources/MbedCore/Pipeline/ArtifactProcessor.swift) | **HALF-BAKED** | `WindowPlanner.pickFPS` and duration-scaled `WindowPlanner.pickContent` (`min(maxFrames, max(2, ceil((hi - lo) * fps)))`) are implemented and unit-tested on synthetic arrays, and `makeThumbnailJPEG` applies `appliesPreferredTrackTransform = true`. **Missing**: (1) `planWindows` uses non-overlapping `lo += windowSeconds` instead of configurable `16s` stride; (2) no live `AVAssetReader` / `AVAssetImageGenerator` 4 fps `32x32` luma extractor is wired yet for in-process `"content"` window planning. |
| **Heylook HTTP Engine (Option A)** | [`HeylookMLXEngine.swift`](../../Sources/MbedCore/Engine/HeylookMLXEngine.swift) | **HALF-BAKED** | Speaks `POST /v1/embeddings` and `DELETE /v1/requests/{id}` on `CancellationError`, retries `429`/`503`, and parses `row.windows`. **Missing**: does not chunk `inputs` into batches of `<= 16` items (the `heylook` `limits.items` cap), so a long text/code file with `> 16` line chunks will 422; also reads full video files into `Data` in memory to base64-encode. |
| **In-Process MLX Swift Engine (Option B)** | [`NativeMLXEmbeddingGemma2.swift`](../../Sources/MbedCore/Engine/NativeMLXEmbeddingGemma2.swift), [`Package.swift`](../../Package.swift) | **HALF-BAKED** | `CheckpointDescriptor` inspects `/Users/fredbliss/Storage/llms/google/embeddinggemma-2-MLX-BF16` (`280` image / `140` video soft tokens, `512`d -> `768`d), and `MLXSwiftLMEmbeddingGemma2Engine` wraps `MLXVLM.EmbeddingGemma2Embedding`. **Missing**: (1) `Package.swift` does not yet link `/Users/fredbliss/mlx/mlx-swift` and `/Users/fredbliss/mlx/mlx-swift-lm`, so `#if canImport(MLXVLM)` is inactive; (2) `MLXSwiftLMEmbeddingGemma2Engine.embedBatch` only embeds whole videos and returns `windows: []` instead of feeding per-window frames via `UserInput.Video.frames(...)`; (3) writes `Data` to a temp file instead of passing file `URL`s directly. |
| **Multimodal & Non-Media Indexing** | [`IndexCoordinator.swift`](../../Sources/MbedCore/IndexCoordinator.swift) | **HALF-BAKED** | Indexes `.image`, `.video` (with `first.windows.count > 1` guard), `.audio`, `.text`, and `.code`. **Missing**: (1) `.document` (`.pdf`, `.rtf`) tries `String(contentsOf: url, encoding: .utf8)` instead of `PDFKit` page extraction (`.pages(startPage:endPage:)`); (2) `.audio` files `> 30s` are not windowed into 30s temporal spans; (3) `.video` soundtracks are not extracted/embedded as audio chunks. |
| **macOS Desktop App (`MbedApp`)** | [`MbedApp.swift`](../../Sources/MbedApp/MbedApp.swift) | **HALF-BAKED** | 3-column `NavigationSplitView`, modality filter, Matryoshka dimension picker, video window sampling picker, drag-and-drop indexing, hybrid text + media attachment search, and `MacVideoPlayerView` (`AVPlayerView`) seeking to `startTimeSeconds`. **Missing**: (1) no **Stop / Cancel** button for in-flight indexing; (2) no clickable `frameTimes` pills in `InspectorView`; (3) no audio player preview for `.audio` hits; (4) no UI toggle between In-Process MLX and `heylookllm` server; (5) no persisted watch folders / `FSEvents`. |
